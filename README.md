# WhatNext Vision Motors - Salesforce CRM

Salesforce CRM implementation for managing vehicles, dealers, customers, vehicle orders, test drives, and service requests.

## Implemented Features

- Custom Salesforce objects, fields, lookup relationships, and tabs
- WhatNext Vision Motors Lightning App
- Auto Assign Dealer record-triggered flow
- Scheduled Test Drive Reminder email flow
- Vehicle stock validation using Apex Trigger and Trigger Handler
- Automatic stock reduction when orders become Confirmed
- Batch Apex for processing Pending orders after stock replenishment
- Scheduled Apex for daily vehicle order processing
